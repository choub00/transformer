# 论文公式修复说明

## 1. 目前问题定位

当前文件 [基于Transformer的股票预测系统_论文初稿.docx](D:\transformer\thesis\基于Transformer的股票预测系统_论文初稿.docx) 里的公式，大部分还是普通文本形式的 LaTeX，例如：

- `$O(n^2)$`
- `\frac{P_{t+H}^{(i)}-P_t^{(i)}}{P_t^{(i)}}`
- `\mathcal{X}_t \in \mathbb{R}^{N \times L \times d}`

这意味着它们不是 Word 的正式公式对象，所以导出、换字体、调整行距、学校模板套用时都容易乱码或错位。

## 2. 已提供的修复脚本

已生成脚本：

- [convert_latex_equations_in_word.ps1](D:\transformer\thesis\convert_latex_equations_in_word.ps1)

用途：

- 识别文档中的行内公式 `$...$`
- 识别“整段就是公式”的段落
- 调用本机 Word，把它们转成真正的 Word 公式对象
- 另存为新文件，避免覆盖原稿

默认输出文件：

- [基于Transformer的股票预测系统_论文初稿_公式修复版.docx](D:\transformer\thesis\基于Transformer的股票预测系统_论文初稿_公式修复版.docx)

## 3. 建议的使用方式

在 PowerShell 里运行：

```powershell
powershell -ExecutionPolicy Bypass -File D:\transformer\thesis\convert_latex_equations_in_word.ps1
```

如果你想看到 Word 打开的过程：

```powershell
powershell -ExecutionPolicy Bypass -File D:\transformer\thesis\convert_latex_equations_in_word.ps1 -Visible
```

## 4. 修完后一定要人工检查

重点检查以下几类公式：

- 分段函数：`\begin{cases} ... \end{cases}`
- 黑板粗体：`\mathbb{R}`
- 复杂上下标：如 `\hat{\mathbf{y}}_{t+H}^{(i)}`
- 带 `\text{}` 的公式
- 多行公式和过长分式

原因：

- Word 对 LaTeX 的支持并不等同于 LaTeX 编译器，复杂公式可能需要手工微调。

## 5. 毕业论文格式建议

为了符合学校论文格式，建议最终版按下面原则处理：

- 正文中文用学校要求字体，通常是宋体或指定模板字体。
- 英文和变量使用 Times New Roman。
- 所有数学公式都用 Word 正式公式对象，不要保留 `$...$` 文本。
- 独立公式单独成段，并居中排版。
- 公式编号用右对齐制表位，不要手敲空格。
- 图表标题、章节标题、参考文献格式，最后统一套学校模板。

## 6. 更稳妥的最终流程

如果后面你还会继续改论文内容，推荐固定流程：

1. 先在 Markdown 中写内容和公式。
2. 再导入 Word。
3. 立即把 LaTeX 公式批量转成 Word 公式对象。
4. 最后只在 Word 里做学校模板排版和编号。

这样比“边写 Markdown 边反复导出 docx”更稳，不容易把公式再次导回纯文本。
